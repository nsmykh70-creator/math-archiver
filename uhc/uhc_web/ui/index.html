UHC Web Archiver

Клиентский веб-интерфейс универсального гибридного кодека (Wasm + доменная предобработка + контроль целостности BLAKE3)

Перетащите файл или архив .uhc сюда или нажмите для выбора файла

Режим 0 — строго без потерь. Режимы 1/2: журналы операций — без потерь (дельта-упаковка), текст — осознанно потерьный «скелет» (транслит + прореживание), восстановление текста не гарантируется.

Готов к работе. Подключите скомпилированный WASM-модуль или используйте встроенный демо-режим.
