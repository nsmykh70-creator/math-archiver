# UHC — Universal Hybrid Codec (Rust + WASM + Web)

Прототип универсального гибридного архиватора, перенесённый из `uhc_web.zip`
и доведённый до рабочего состояния:

- `uhc_workspace/` — нативное ядро на Rust: параллельная обработка блоков
  (rayon), zstd, BLAKE3 на каждый блок и на контейнер, дельта-упаковка
  журналов операций (varint LEB128 + ZigZag), CLI.
- `uhc_web/wasm_bridge/` — тот же контейнер (`UHCW`) в WASM через
  wasm-bindgen (DEFLATE вместо zstd — без C-зависимостей в браузере).
- `uhc_web/ui/` — веб-интерфейс (drag-and-drop, режимы 0/1/2, метрики,
  скачивание `.uhc`). Собранная копия сайта лежит в `/docs` репозитория —
  это GitHub Pages.

## Статус и что было исправлено при интеграции

Прототип собирался и работал в режиме 0 (без потерь) и на дельта-журналах,
но **режимы 1/2 для текста падали** при распаковке: контейнер хешировал
исходник, а декодер восстанавливал «скелет» (транслит + прореживание), и
проверка BLAKE3 не проходила (`container BLAKE3 checksum failed`).
Исправлено: хеш контейнера считается по потоку, который действительно вернёт
декодер (для режима 0 — исходник, для lossy-режимов — детерминированный
скелет). Целостность по-прежнему проверяется: повреждение любого байта
ловится.

## Режимы

| Режим | Журналы операций | Текст | Бинарные данные |
|---|---|---|---|
| 0 | без потерь | без потерь | без потерь |
| 1 (дельты/прореживание) | без потерь (varint-дельты) | **потерьный скелет** (транслит + удаление гласных) | без потерь |
| 2 (агрессивный) | без потерь (varint-дельты) | **потерьный скелет** (агрессивнее) | без потерь |

Режимы 1/2 для текста — осознанно потерьный слой (как в концепции проекта);
они предназначены для поисковых индексов и черновиков, не для архивов,
которые нужно восстановить.

## Сборка и запуск

### CLI (нативный)

```bash
cd uhc/uhc_workspace
cargo build --release
./target/release/uhc_cli <input_file> <0|1|2> [zstd_level]
```

### Тесты

```bash
cd uhc/uhc_workspace
cargo test          # 6 тестов roundtrip: все режимы, многоблочный ввод, порча данных
```

### Веб-версия

```bash
rustup target add wasm32-unknown-unknown
cargo install wasm-pack   # или скачать бинарник с github.com/rustwasm/wasm-pack
cd uhc/uhc_web/wasm_bridge
wasm-pack build --target web --out-dir ../ui/pkg
# сайт: скопировать содержимое ui/ в docs/ (или запустить сервер в ui/)
python3 -m http.server 8080 --directory uhc/uhc_web/ui
```

## Результаты проверки

- cargo test: 6/6 OK (после исправления хеша).
- WASM-модуль: журнал (mode 1) и текст/бинарные данные (mode 0) — побайтовый
  roundtrip; текст (mode 1) — детерминированный скелет
  («Быстрая коричневая лиса…» → «Bystra korchnva lisa prgt chrz…»);
  повреждение байта контейнера ловится.
- `mixed_10mb_compression_test.bin` (10 МБ): 51,0% за 58 мс (сжатие),
  20 мс (распаковка), roundtrip побайтовый.

## Отличия от Python-конвейера `algebraic/`

| | `algebraic/` (Python) | `uhc/` (Rust) |
|---|---|---|
| Слой 2 | равенства, дельта-журнал, предсказание текста | дельта-журнал, транслит/скелет |
| Слой 3 | LZMA2 | zstd / DEFLATE |
| Целостность | roundtrip-проверка каждого кандидата | BLAKE3 блока + контейнера |
| Использование | CLI / Python API | CLI / браузер (WASM) |

Направления развития: перенос идеи равенств (`numeq`) и предсказателя
(`textcodec`) в Rust-ядро; снапшоты дельта-журнала как в `numseries`;
восстановление скелета по словарю (сейчас режимы 1/2 для текста однонаправленные).
