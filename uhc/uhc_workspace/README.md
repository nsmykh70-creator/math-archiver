# UHC (Universal Hybrid Codec) — Rust Core & CLI

Рабочий каркас ядра универсального гибридного кодека на Rust с поддержкой:
- многопоточной обработки блоков через `rayon`;
- сжатия через `zstd` с автоопределением выгодности (`zstd` vs `stored`);
- режимов `0` (строго без потерь), `1` (лёгкое прореживание), `2` (агрессивный скелет / дельты);
- бинарной упаковки числовых дельта-потоков (`varint` LEB128 + `ZigZag`);
- контрольных сумм `BLAKE3` для каждого блока и всего контейнера (`UHC2`).

## Сборка и запуск

```bash
cargo build --release
./target/release/uhc_cli <input_file> <0|1|2> [zstd_level]
```
