# Результаты: контейнер MAF2 × компрессоры (xz/LZMA2, zstd, gzip)

Методика: для каждого набора — три компрессора на исходных данных и те же три внутри контейнера MAF2 (авто-выбор слоя: словесно-формульный кодек, текстовый ярус textlayer, varint длинных чисел; лучший проверенный кандидат).
