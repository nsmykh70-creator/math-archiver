# steno — стенографические аккорды (Rust, lossless)

Кодирование текста аккордами пронумерованной клавиатуры (24 клавиши,
1..=24) с полной, без потерь обратимостью. Только стандартная библиотека,
внешних зависимостей нет.

## Модель

- **Аккорд** — одновременное нажатие подмножества клавиш; хранится битовой
  маской `u32` (бит `k-1` = клавиша `k`). API: `Chord::from_keys`,
  `Chord::from_mask`, `.keys()`, `.mask()`, `.popcount()`, `to_3_bytes` /
  `from_3_bytes` (3 байта на аккорд), `Display` как `1-8-24`.
- **Упаковка** `pack_bytes` / `unpack_bytes` — плотный битовый поток
  `[u32 BE: число аккордов] + биты (MSB-first, без выравнивания)`:
  - одиночная клавиша — 5 бит;
  - аккорд из двух клавиш — код 25 + 2×5 бит (15 бит, клавиши по возрастанию);
  - прочий аккорд — код 24 + 24 бита маски (29 бит);
  - хвостовые биты выравнивания обязаны быть нулями (проверяются).

## Нормализация гомоглифов

Двенадцать визуальных пар кириллица/латиница (`А/A`, `В/B`, `Е/E`, `К/K`,
`М/M`, `Н/H`, `О/O`, `Р/P`, `С/C`, `Т/T`, `У/Y`, `Х/X`) сводятся к одному
каноническому символу: один аккорд обозначает ОБЕ буквы (`с` и `c`,
`то` и `to`, `не` и `he`). Исходный алфавит и регистр восстанавливаются:

- **алфавит** — «защёлка» (`script_cyr`/`script_lat`): маркер пишется только
  при смене; старт потока — кириллица; маркер `script_neu` («прочее»)
  зарезервирован и кодировщиком не используется;
- **регистр** — маркеры «Заглавный»/«ВЕРХНИЙ» перед словом; нижний — по
  умолчанию, без маркера.

Слова, не подходящие под канонические схемы (смешанный регистр `FooBar`,
смешанный алфавит `kо`), и любые неизвестные токены (цифры, эмодзи, CJK)
уходят в **fallback**: аккорды `raw_run` (клавиши 1+2) и `raw_byte` (1+3),
дальше нибблы на клавишах 9..24 (5 бит на полубайт). UTF-8 проверяется при
декодировании — обратимость 100% для любого Unicode-текста.

## Словарь

`StenoDictionary::build_default()`: ~390 частотных русских и английских
слов + 20 знаков. Раскладка одиночных клавиш: 1 — пробел, 2..4 — регистр,
5..6 — алфавит, 7 — точка, 8 — запятая; клавиши 9..24 — нибблы. Слова
занимают парные аккорды (15 бит), пока пары не кончатся, далее — широкие
маски (29 бит). Таблицы двунаправленные, коллизии масок проверяются при
сборке (`DictionaryConflict`).

## Использование

```rust
use steno::{pack_bytes, unpack_bytes, StenoDictionary};

let dict = StenoDictionary::build_default()?;
let chords = dict.encode_to_chords("Привет, мир!")?;
let bytes = pack_bytes(&chords);
let back = dict.decode_from_chords(&unpack_bytes(&bytes)?)?;
assert_eq!(back, "Привет, мир!");
```

```bash
cargo test        # 16 тестов: roundtrip, гомоглифы, ошибки, property-тест
cargo run --release   # демонстрация с размерами в байтах
```

## Замеры (cargo run --release)

| Текст | Исходник | Закодировано | Доля |
|---|---|---|---|
| Русское предложение (словарь) | 107 Б | 42 Б | 39% |
| Длинный абзац RU (3 строки) | 351 Б | 123 Б | 35% |
| Английское предложение | 63 Б | 59 Б | 94% |
| Смесь с эмодзи/CJK/смешанным регистром | 93 Б | 116 Б | 125% |

Словарный текст выигрывает в 2–3 раза; строка из редких слов, эмодзи и
смешанных регистров немного расширяется (fallback) — цена обратимости
на непредсказуемом материале. Больше словарь — лучше сжатие.

## Структура

- `src/lib.rs` — модель аккорда, битовая упаковка, нормализация, словарь,
  кодер/декодер, 16 unit-тестов `#[cfg(test)]`;
- `src/main.rs` — демонстрация: раскладка, словарь, примеры, проверка
  побайтового совпадения.
